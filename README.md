# Miao Sun Academic Homepage

This is a static academic homepage for:

https://watercube001.github.io/

## Deploy on GitHub Pages

1. Open the repository named `watercube001.github.io`.
2. Delete old files if needed.
3. Upload all files in this folder to the repository root:
   - `index.html`
   - `style.css`
   - `assets/profile.png`
4. Add your latest CV as `Sun_Miao_CV.pdf` in the same root folder.
5. Commit and push.
6. Visit `https://watercube001.github.io/`.
